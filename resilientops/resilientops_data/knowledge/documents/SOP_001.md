# Shipment exception investigation

Document SOP_001 | Version 1.0 | Effective 2024-01-01

Fictional internal document for the ResilientOps simulation. This is not an actual supplier audit, legal policy or certification.

## 1. Trigger

An ETA update or external report indicates possible delay.

## 2. Procedure

Validate the observation and shipment ID. Preserve the original ETA. Retrieve latest shipment updates, route and PO lines. Establish what is confirmed versus assumed. Ask Impact to recompute receipts and shortages using the same snapshot.

## 3. Completion

Return confirmed timing changes, affected shipments, citations, unresolved contradictions and evidence availability time. Do not write an ETA based only on weather severity.
