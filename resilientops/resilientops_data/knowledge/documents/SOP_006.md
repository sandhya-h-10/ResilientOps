# Decision and execution review

Document SOP_006 | Version 1.0 | Effective 2024-01-01

Fictional internal document for the ResilientOps simulation. This is not an actual supplier audit, legal policy or certification.

## 1. Trigger

Recovery has produced a validated plan.

## 2. Procedure

Compare against the no-action baseline using one objective and data snapshot. Present costs, residual impact and evidence. Request authorization for the exact version. Pause. On approval, have the action service revalidate and execute idempotently.

## 3. Completion

Record approval, execution result and monitoring status separately. Never label a proposed plan as executed. Record failure and escalate if revalidation blocks it.
